# elfcode-core

The domain types and process protocol shared by the [elfcode](https://github.com/maartenpeels/elfcode) crates.

This crate is an implementation detail. Use [`elfcode`](https://crates.io/crates/elfcode) to write solutions and [`cargo-elfcode`](https://crates.io/crates/cargo-elfcode) to run them. Its API can change in any release.
